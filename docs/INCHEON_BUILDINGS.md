# 인천 건물 연결

2026-09-24. VWorld 추가 소스 계획의 2단계 구현이다. 보호구역·토지이용계획·지적도는 자료 조회만 확인했으며 지도 기능에는 연결하지 않았다.

## 사용 방법

- 인천 첫 방문은 평면이다. 지도 설정의 **입체 현황판**을 선택하면 건물 보기로 전환한다.
- PC는 줌 15.5, 모바일 화면은 줌 16 이상에서 건물을 조회한다. 그 아래에서는 확대 안내를 표시한다.
- URL의 `scene=city` 또는 `scene=flat`이 우선이며, 다음으로 인천 전용 저장값을 읽는다. 전북 저장값과 기본 입체 동작은 유지한다.
- 건물은 학교 선택을 가로채지 않는다. 높이는 원천 제공값, 지상층수 × 3m의 추정값 순서로 사용하고 모두 없으면 윤곽으로 표시한다.
- 건물 조회 시각은 원천 자료의 갱신일이 아니다. 요청 실패 시 기본 지도와 학교 검색을 유지하며 재시도할 수 있다.
- 작은 화면에서 설정과 안내가 길어지면 해당 영역을 스크롤해 재시도 버튼까지 접근할 수 있다.

## 지역 범위

`src/lib/profiles/incheon.ts`의 건물 범위는 `public/data/incheon/regions.geojson`에서 계산한 `[124.60979, 37.01811, 126.79367, 37.98431]`이다. 줌 16 기준 한 타일의 여백을 더하며 서버 허용 범위와 지도 표시 범위가 같은 계산을 사용한다.

범위는 인천과 도서를 감싸는 사각형으로, 타일 경계 근처의 인접 지역 일부가 함께 보일 수 있다. 인천 행정구역 폴리곤으로 개별 건물을 잘라내는 기능은 아니다. 전북 범위는 기존 값으로 분리했으며, 인천 서버에 전북 타일을 요청하면 거부한다.

## 로컬·운영 설정

| 변수 | 용도 |
| --- | --- |
| `NEXT_PUBLIC_EDU_MAP_PROFILE=incheon` | 인천 클라이언트·서버 프로필 |
| `NEXT_PUBLIC_VWORLD_KEY` | 브라우저에서 사용하는 배경지도 키 |
| `VWORLD_BUILDING_KEY` | 서버 데이터 API 인증값 |
| `VWORLD_BUILDING_DOMAIN` | 해당 키로 승인된 서비스 도메인 |
| `BUILDINGS_ENABLED=false` | 서버 건물 응답 중지(503, 캐시 없음) |
| `NEXT_PUBLIC_BUILDINGS_ENABLED=false` | 건물 UI 및 서버 요청 비활성화; 클라이언트 반영에는 재빌드 필요 |

이번 로컬 검증에서는 같은 프로젝트에 이미 등록된 VWorld 키가 데이터 API에서도 인증됨을 확인하고 서버용 변수에 연결했다. 로컬 `.env.local`의 기존 내용은 보존하며, 키 값은 소스·문서·검사 결과에 넣지 않는다. 운영 배포에는 `VWORLD_BUILDING_KEY`를 Secret으로, `VWORLD_BUILDING_DOMAIN`을 Config로 Vercel Production 환경에 등록해야 한다. 환경 변수는 새 배포부터 반영된다.

## 원천 검증과 재현

[GIS건물통합정보 공식 설명](https://www.data.go.kr/data/15123970/openapi.do)을 기준으로 `LT_C_BLDGINFO`를 조회한다. 11개 군·구를 대표하는 학교와 백령·연평·덕적을 포함한 14개 표본 타일에서 총 3,683개의 건물 응답을 확인했다. 이는 표본 응답의 합계이며 인천 전체 건물 수가 아니다.

독립 스크립트는 키가 준비된 로컬 환경에서 실행한다.

```powershell
node --import tsx scripts/verify-incheon-vworld.ts
```

스크립트는 `output/vworld-expansion/qualification.json`에 키 없는 결과를 저장한다. 건물의 페이지·총건수·중복 ID·좌표 범위와 높이 결측을 검사하고, 후속 후보 자료는 학교 주변의 작은 범위에서 응답·필드·빈 결과를 확인한다. 호출 한도와 준비된 인증을 확인한 상태에서만 실행한다.

원천 개체의 최종 갱신일과 계정별 일일 요청 한도는 이 표본 결과로 확인할 수 없다. 공공데이터포털의 자료 설명 시점과 API 조회 시각을 구분한다.

- `tests/unit/incheon-buildings.test.ts`: 실제 인천 경계·562개 학교 위치 포함, 인천/전북 격리, 서버의 빈 결과·범위·기능 중지 처리.
- `tests/components/useScene.test.tsx`: 첫 화면, URL 우선순위, 저장값의 지역 분리, 저장소 오류와 기능 중지.
- 기존 `tests/unit/buildings.test.ts`: 높이·페이지·완전성·요청 취소·캐시·비밀정보 마스킹.
- 실제 브라우저 검사는 모의응답 검사와 구분한다. 모바일 화면 크기 검사로 실제 모바일 기기 성능을 보증하지 않는다.

2026-09-24 로컬 검증: 전체 855개, 최종 설정 화면 보완 후 대상 23개, 전북 모의응답 브라우저 2개 검사 통과. 인천 실제 자료의 본토·도서 10회 이동, 390px·320px, 3종 화면 구성, 학교 선택·지표 변경·오류 재시도를 확인했다. TypeScript·변경 파일 lint·인천 production build가 통과했으며 production 로컬 실행에서도 실제 건물을 확인했다. 운영 배포는 하지 않았다.
