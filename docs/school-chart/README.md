# 학교 원통 그래프

입체 현황판에서 현재 필터에 포함된 학교의 선택 지표를 원통 높이로 표시한다. 기본값은 원통이며 `schoolChart=columns|dots`로 공유·복원한다. 평면에서는 기존 점 표시를 유지한다.

- 높이는 0부터 정비례한다. 반지름은 5px로 동일하다. 원래 위치 점도 5px로 남겨 위치와 클릭 대상을 유지한다.
- 분모는 필터에 관계없이 전북 전체 학교의 해당 지표 최댓값이다. 확대에 맞춰 원통의 시각적 크기를 조절하며, 같은 확대 수준에서 필터를 바꿔도 높이는 변하지 않는다.
- 학생수·학급수·교원수·학급당 학생수·교원당 학생수·학교수·소규모학교 수·신입생 0명 학교수·일반학교 특수학급수/학생수를 지원한다. 특수교육 문제의 특수학교 수는 학교당 1교로 표시한다.
- 학교별 값이 없는 지역 지정·지역 비율·과거 증감 등에는 점을 유지하고 이유를 표시한다. 지역 값을 개별 학교에 복제하지 않는다.
- 0과 결측은 높이 0, 실제 값과 결측 여부는 툴팁에서 확인한다. 학교명은 원통 위에서 11px로 표시하고 충돌도 해당 높이에서 계산한다.
- 구현은 deck.gl [ColumnLayer](https://deck.gl/docs/api-reference/layers/column-layer)를 사용한다. 학교 통계는 건물 높이·통계와 분리한다.

## 검증

- 자동 테스트 752개, TypeScript, lint(기존 경고 2개), production build 통과.
- 학교/교육문제 기존 브라우저 테스트 9개 통과.
- 새 브라우저 테스트 3개: 지표별 높이 비례·필터 기준 유지·점/원통 전환·뒤로가기·새로고침·지역 전용 지표·특수학급 지표·실제 원통 클릭·모바일 전환 통과.
- 운영 배포 후 실제 배경지도로 학생수/교원수 범례, 점 전환, 뒤로가기, 모바일 화면 검증 통과. [PC 화면](desktop.png), [모바일 화면](mobile.png).

## 학교수 높이 보정

학교수 계열(학교수·소규모학교 수·신입생 0명 학교수·특수학교 수)은 개별 학교 값이 0/1이다. 최댓값 1을 원통 최대 높이로 정규화하면 모든 해당 학교가 과도하게 높아지므로, 학교당 1교를 낮은 동일 높이(기존 최대 시각 높이 150 대비 12)로 표시한다. 범례도 `원통 1개 = 학교 1교`로 구분한다. 학생수 등 수량 지표의 비례 높이는 유지한다. 단위 테스트 5개와 그래프 브라우저 테스트 4개로 검증했다.
