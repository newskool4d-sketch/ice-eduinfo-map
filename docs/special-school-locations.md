## 재생성과 검증

- 원본: `data/manual/special-school-locations.json`. 학교별 KEDI 식별자, 학교명, 시군, 공식 지도 URL, 주소, 확인일을 보존한다.
- `npm run data:schools`가 누락 좌표에만 보완 자료를 적용한다. 식별자 중복·학교명/시군/주소 불일치·잘못된 좌표·기존 좌표 덮어쓰기는 오류로 중단한다.
- `public/data/schools.json`의 학교 753곳 모두 지도에 표시 가능하다. 기존 학교 ID, 학생·학급·교원 수, 통계 기준일과 표준 CSV 기준일은 변경하지 않았다.
- 학교 상세에 공식 위치 안내 링크와 별도의 위치 확인일을 표시한다.
- 데이터 검증: 11곳 모두 해당 시군 경계 검증 통과. 기존 교육문제 집계(일반학교 특수학급 559학급, 특수학교 11교)를 유지한다.
- TypeScript, lint(기존 경고 2건만), production build 통과. 학교 검색/선택/확대, 특수교육 지도, 모바일 교육문제, 좌표 누락 대체 경로 브라우저 테스트 9개 통과.
- 운영 배포 완료: https://jb-edu-map.vercel.app (배포 `jb-edu-6lupw6vpg`). 운영 JSON의 11곳 좌표, 덕유샘학교 선택·주소·공식 링크, 특수학교 필터 11/11 표시를 Playwright로 확인했다. 실제 배경지도와 덕유샘학교 점의 화면도 확인했다.
