# 교육현황 지도

기본 화면은 밝은 무채색 도시와 학생 분포다. 배경 건물은 기존 API·타일 캐시를 재사용하며 일반 보기 alpha 46/255, 교육문제 보기 38/255로 낮춘다. 건물 높이는 지표값이 아니며 학교 데이터와 건물 도형을 연결하지 않는다.

| 데이터 | 자동 표현 | 비교 기준 |
| --- | --- | --- |
| 학생·학급·교원 수 | 줌 13 미만 가중 히트맵, 확대 시 크기·색 | 전북 전체 학교 기준 |
| 학급당·교원당 학생수 | 고정 크기 점 + 연속 색 구간 | 값이 크다는 뜻이며 과밀 판정이 아님 |
| 작은학교·신입생 0명·학교수 | 해당 학교 강조 | 해당 없음과 자료 없음 구분 |
| 특수학급·학생수 | 보라색 수치 + 특수학교 마름모 | 일반학교와 특수학교 범위 구분 |
| 증감률·폐교 등 지역 집계 | 시군 면 색 | 학교별로 배분하지 않음 |

히트맵은 학교 위치의 상대 집중도이며 거주지·통학권·인구밀도가 아니다. 검색하거나 시군을 선택해도 수치별 색 기준과 히트맵 도메인을 재계산하지 않는다. GPU가 부동소수점 혼합을 지원하지 않으면 학교별 수치 표현으로 전환하고 안내한다. 0과 결측값은 별도 색으로 표시한다.

특수학급 원지표는 특수학교를 포함해 800학급·3,804명이다. 교육문제의 일반학교 특수학급 지표는 559학급·2,483명이며 특수학교 11개교를 별도로 표시한다. 패널 탭을 바꿔도 이 범위는 유지된다.

## 화면과 URL

- 시작 화면의 검색·통계 패널과 지도 설정은 접혀 있다.
- 빠른 선택 5개와 전체 지표 메뉴를 함께 제공한다. 모바일에서는 빠른 선택이 드롭다운이다.
- `schoolChart=auto`가 기본이다. 기존 `columns`, `dots` 링크와 평면·입체 설정은 유지한다.
- 학교 이름은 줌 15부터, 선택 학교는 우선 표시한다. 건물 조회 임계값은 데스크톱 15.5, 모바일 16이다.
- 지표 이름·집계 범위·기준일·색 범례는 지도 오른쪽 아래에 모인다. 모바일에서는 설명을 펼쳐 읽을 수 있다.

## 검증

`npm test`, `npm run typecheck`, `npm run lint`, `npm run data:validate`, `npm run build`로 기본 검증한다. `npx playwright test`는 자동/원통/점, 지표 전환, URL 복원, 모바일 카드와 범례 배치, GPU 대체 표현 및 기존 검색·학교 상세·접근성을 확인한다. 실서비스 전용 테스트는 별도 환경변수가 있어야 실행된다.

`e2e/education-city.spec.ts`가 화면 캡처를 `test-results/education-city-*.png`에 생성한다. 실제 브라우저에서도 브이월드 배경·건물 로딩과 390px 모바일 학교 선택을 확인했다.
