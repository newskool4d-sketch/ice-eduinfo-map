# 학생 차이 91건·교원 562개 기록 전수 대조

2026-09-23. 남은 학생 수 88건 → 교원 전체 → 과거 주소 근거 순으로 확인했다. 기존 표본 3건은 같은 날 보존한 응답을 재사용했다. 앱 수치·주소·추세 연결은 변경하지 않았다.

## 결과

|요구사항|실행 및 결과|한계|
|---|---|---|
|학생 수 88건 대조|88건 모두 학교알리미와 KESS·앱이 일치. 기존 3건 포함 **91/91건 일치**|교육청 학교현황 파일과 차이가 발생한 행정적 원인은 미확정|
|교원 전수 대조|**562개 기록 조회**, 숫자 공시가 있는 **560개 모두 총계·정규·기간제 구성 일치**|휴교 분교 2개는 숫자 공시 없음|

전체 판정은 **PARTIAL**이다. 조회 실행 완료와 숫자·주소의 검증 범위를 구분한다.

## 1. 학생 수

학교알리미 MCP의 2026년 성별 학생수(63)를 조회했다. 91건 각각 남+여=총계, 일반학년+특수+순회=총계를 확인하고 KESS와 앱의 학생 수에 대조했다.

- 신규 88건 + 이전 3건 = 91건, 전부 일치한다.
- 91건은 KESS와 교육청 학교현황 사이에 차이가 있던 기록의 전체다. 인천 전체 562개 학생 기록을 새로 대조한 것은 아니다.
- 교육청 원본 값·셀 위치·차이를 보존했다. 차이의 행정적 원인 확정은 여전히 0건이다.
- 일반학급 학년별 값만 합산해 특수학급 학생을 누락하지 않았다.
- 광성고는 현재 제물포구 조건과 학교명 찾기에서 검색되지 않았으나, 원자료 당시 중구 조건에서는 435명이 반환됐다. 서울 광성고를 대신 사용하지 않았다.

해당 공시는 교육통계 연계 자료다. **별도 공개 경로의 일치**이며 별개 독립 조사에서 얻은 검증값이라는 뜻은 아니다.

## 2. 교원 전체

앱의 562개 학교·분교를 고정 명단으로 삼고 직위별 교원 현황(22)을 조회했다. 신규 559건과 이전 3건을 합쳤다. 신검단초는 현행 검단구에서 검색되지 않아 원자료의 서구 조건으로 확인했으며, 광성고는 중구 조건을 사용했다.

|학교급|대상 기록|숫자 공시 확보|학교알리미 강사 제외 합계|KESS·앱 합계|
|---|---:|---:|---:|---:|
|초등|276|274|10,370|10,370|
|중등|147|147|6,390|6,390|
|고등|129|129|7,432|7,432|

560개 기록의 원 총계 25,235명에서 강사 315명을 한 번 제외하면 **24,920명**이다. 직위별 정규 교원 20,320명 + 기간제 4,600명과도 일치한다. 학교별 총계뿐 아니라 정규·기간제 구성도 KESS의 원본 셀과 각각 대조했다.

### 강사와 휴직 인원의 중복 차감 방지

[2026 정보공시 입력 지침](https://www.goe.go.kr/resource/goe/na/bbs_2675/2026/03/e76881ab-1309-4368-9c1a-c009e8ebd3f8.pdf) PDF 109·110·112쪽(책자 103·104·106쪽)을 확인했다. 기준일은 2026-04-01이다. 강사에는 원어민 강사가 포함되며, 원어민·휴직 인원은 이미 포함된 인원을 별도로 표시한다.

비교식은 **공시 총계−강사**다. 인천외고의 원 총계 64명, 강사 5명, 원어민 4명은 64−5=59명으로 비교한다. 원어민 4명을 또 빼지 않는다. 전체 원어민 4명은 강사 315명의 부분집합이며 휴직 교원도 다시 차감하지 않았다.

560개 관측값의 합계가 앱 전체 합계와 같다는 사실과 562개 전부 숫자 공시를 확보했다는 주장은 구분한다. 이번 24,920명은 **학교별 공시 재집계**이며 별도 발표된 인천 총계 표를 새로 확보한 것은 아니다.

## 3. 과거 주소 근거

### 문일여자고등학교: 2022년 1건

[정부의 2015-03-10 매점 위탁 공고](https://www.mpva.go.kr/mpva/selectBbsNttView.do?bbsNo=32&key=145&nttNo=47251) 본문에서 학교 소재지 **구월로372번길 98**을 확인하고 원문을 보존했다. 이 번호를 실제 사용한 공식 근거가 있다.

현재 56번지는 사용자 확인·학교알리미·2024 이후 KESS에 근거가 있다. 검색 결과에는 교육청의 2022-12-26 채용 공고에도 56번지가 나타났지만, 직접 조회에서는 시스템 안내만 반환됐다. 검색 결과는 추가 확인 후보로만 기록했다.

2015년 공고만으로 2022년 당시 위치, 98→56의 정확한 적용일, 이전·주소 정정 여부를 확정하지 않았다.

### 인천청천초등학교: 2022·2023년 2건

- [옛 공식 홈페이지](https://icce.icees.kr/main/ichonges/index.html)에서 **산청로127번길 12-5**, 전화 032-516-2823, 팩스 032-516-2830을 확인했다. 화면 작성일은 확인되지 않아 검색 수집 시점을 주소 적용일로 사용하지 않았다.
- [2024년 교육청 공고](https://www.ice.go.kr/ice/na/ntt/selectNttInfo.do?mi=10997&nttSn=3274982) 본문 날짜는 **2024-02-16**, 학교 소재지는 **산청로127번길 10**이다.
- [학교 연혁](https://icce.icees.kr/sub/info.do?m=0102&s=ichonges)에 **2023-11-30 신관·운동장·병설유치원 완공**이 기재돼 있다. 이를 주소 변경일이나 주소 변경 원인으로 단정하지 않았다.

옛 번호와 현재 번호의 실사용 근거는 확보했지만 주소 변경·정정 공문이나 명시적인 이전 이력은 확보하지 못했다. 남은 3개 추세 연결과 과거 좌표는 자동 확정하지 않았다.
